One pickup line, 200 characters at most, spoken by a vending machine to a passing human: "Are you exact change? Because I've been short all day - and you're the first thing in this hallway I'd never get stuck on."

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt`.
